# 🤖 Autonomous SEO Content Engine
### Enterprise-Grade AI Automation for WordPress

This repository contains the technical blueprint for a zero-touch SEO pipeline. It transforms a single keyword in Google Sheets into a 1,200+ word, high-authority article published directly to WordPress.



---

## 🛠 The Architecture
- **Trigger:** Google Sheets (with Null-Status Logic Gates)
- **Brain:** Google Gemini 2.5 Flash (E-E-A-T Optimized)
- **Visuals:** Pexels API (Automated Landscape Sourcing)
- **Endpoint:** WordPress REST API + Rank Math SEO

## 🚀 Key Technical Features
- **E-E-A-T Logic:** Custom system instructions forcing First-Person Perspective and 60+ Flesch Readability.
- **JSON Sanitization:** Automatic handling of markdown backticks and HTML single-quote enforcement.
- **TOC Optimization:** Injected `\\n` breaks to ensure Table of Contents plugins recognize AI-generated headers.
- **SEO Automation:** 100% automated metadata, slugs, and alt-text mapping.



## 📁 How to Use
1. Import the `The Autonomous SEO Engine Architecture.blueprint.json` into a new **Make.com** scenario.
2. Connect your Google Sheets, Google AI (Gemini), and WordPress credentials.
3. Add your target keywords to the "Keyword" column and watch the engine scale your site.
